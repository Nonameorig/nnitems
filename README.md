NNItems is a powerful and lightweight Minecraft plugin designed for Spigot/Paper 1.21 that introduces highly unique, custom weapons and interactive menus to your server.
The core feature of this version is the Defender Sword—a specialized custom item complete with its own dedicated management GUI.

🌟 Features

• Custom Items: Easily bring unique weapons and gear into your gameplay.
• Defender Sword: A premium custom sword tailored for combat and utility.
• Interactive GUI: Open a clean, user-friendly in-game interface to manage or obtain the Defender Sword instantly.
• Optimized for 1.21: Built natively using the modern 1.21 Spigot/Paper API.

🛠️ Commands & Permissions

The plugin includes built-in commands with secure permission nodes to give admins full control:
Command	Description	Permission	Default
/defender	Opens the Defender Sword GUI menu	nnitems.defender	OP
/nnitems	Main administrative command for the plugin	nnitems.admin	OP

⚙️ Installation

1. Download the latest .jar file from the releases section.
2. Drop the file into your server's plugins folder.
3. Restart or reload your server.
4. Use /defender to explore the custom GUI!
